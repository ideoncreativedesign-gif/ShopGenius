# Decision Log

Lightweight, append-only, newest first. This is what prevents Claude conversations from
becoming the invisible memory of the project.

Log a decision when it constrains future work, when we rejected a real alternative, or when a
future teammate would otherwise ask "why is it like this?"

**Status values:** Proposed · Accepted · Tested · Rejected · Revisit

## D-001 — Use this repo as the source of truth

- **Date:** —
- **Status:** Accepted
- **Decision:** GitHub holds canonical project artifacts. Notion is the working environment.
  Claude is the thinking environment.
- **Why:** AI-assisted work generates a high volume of plausible documents. Without one
  versioned place, the project's reasoning disperses into chat history.
- **Alternatives rejected:** Notion as source of truth (no diffs, no review gate); no formal
  source of truth (fails at two people).
- **Evidence:** Studio guideline §20–§23.
- **Affects:** everything.
- **Revisit when:** the team outgrows two contributors.
