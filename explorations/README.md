# Explorations

Timeboxed probes. This is where continuous exploration happens without destabilizing the source
of truth.

An exploration is allowed to fail, be abandoned, or be embarrassing. What it is not allowed to
be is undocumented — a probe with no writeup is indistinguishable from work that never happened,
and we'll run it again in four months.

## Rules

- Each exploration gets an ID (`EXP-001`) and a folder.
- State the question and the timebox **before** starting. If you can't state the question,
  you're browsing, not exploring — that's fine, but log it in `../inspiration/` instead.
- An exploration cannot change `docs/` directly. It can produce a decision proposal, which goes
  through `../docs/decisions.md`.
- Kill it when the timebox ends even if it's going well. Extending is a decision; drifting isn't.
